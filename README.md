# Pokédex App

## Descripción
Proyecto desarrollado con Ionic y Angular como parte de una actividad escolar.

## Tecnologías utilizadas
- Ionic
- Angular
- TypeScript
- Git y GitHub

## Estructura de ramas

**main:** Rama principal que contiene la versión base del proyecto.

**develop:** Rama utilizada para integrar y organizar los cambios del proyecto.

**pages:** Rama destinada al desarrollo de las páginas de la aplicación.

## Control de versiones
El proyecto utiliza Git y GitHub para administrar los cambios. Las ramas main y develop cuentan con reglas de protección.
